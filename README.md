# AI Prep 30 Days

Khóa tự học 30 ngày chuẩn bị cho chương trình AI Thực chiến: Python → Dữ liệu & ML → LLM → Sản phẩm AI.

## Cấu trúc

Mỗi ngày một thư mục `ngayXX/` (luôn 2 chữ số):

| Tuần | Ngày | Nội dung |
| --- | --- | --- |
| 1 | `ngay01`–`ngay07` | Python từ con số 0, Git, kiểm tra tuần 1 |
| 2 | `ngay08`–`ngay14` | NumPy, Pandas, SQL, Machine Learning, kiểm tra tuần 2 |
| 3 | `ngay15`–`ngay21` | Mạng nơ-ron, LLM, prompt, API, vibe coding, kiểm tra tuần 3 |
| 4 | `ngay22`–`ngay30` | RAG, agent, MCP, FastAPI, Docker, đồ án cuối khóa |
